## Roblox Studio Setup

### Requirements
- Rojo 7.x: https://github.com/rojo-rbx/rojo/releases
- Roblox Studio (latest)

### Steps

1. **Unzip** this file
```
unzip AF51-RBX-AF51-TYCOON-build_tycoon_8e278173.zip -d tycoon-project
cd tycoon-project
```

2. **Start Rojo**
```
rojo serve
```
Output should show: `Rojo server listening on localhost:34872`

3. **Connect from Roblox Studio**
   - Open Roblox Studio
   - Plugins → Rojo → Connect
   - URL: `http://localhost:34872`
   - Click Connect

4. **Play Test**
   - Press F5 (Play Solo)
   - Console should show: `[AF51-RBX] ✓ Server runtime ready — tycoon`
