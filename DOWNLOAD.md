## 🛠 Installation (3 Steps)

### 1. Download & Extract
```bash
# Download
curl -L https://github.com/janijukka-hue/af51-rbx-factory-v23/archive/refs/heads/main.zip -o af51.zip

# Extract
unzip af51.zip
cd af51-rbx-factory-v23-main
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start
```bash
# Terminal 1: Start backend
npm run server

# Terminal 2: Start frontend
npx expo start --web --clear
```

**Done!** Open browser at `http://localhost:8081`
